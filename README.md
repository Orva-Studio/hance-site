# hance-site

Marketing site for [Hance](https://github.com/Orva-Studio/hancer) — a cinematic film-look engine that runs locally, GPU-accelerated, as a single binary.

Built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com).

## Develop

```sh
bun install
bun run dev
```

## Build

```sh
bun run build
bun run preview
```
